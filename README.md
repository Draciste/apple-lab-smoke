# Synthetic macOS 27 browser probe

This standalone repository contains only synthetic fixtures. It runs manually via `workflow_dispatch` on GitHub.com standard `xcode-27` (Apple Silicon), with a 30-minute timeout and one concurrency group. The job is gated on the event and context reporting a public repository. It checks Darwin/arm64 at runtime and retrieves exactly the event commit over anonymous HTTPS. Do not add private code, secrets, personal paths or data. The fixture checks English/Czech JSON through a subprocess using Unicode directory and file names. It serves synthetic HTML on loopback and attempts headed sessions with genuine Safari/safaridriver, stock Firefox/geckodriver and Chrome/chromedriver, using the W3C WebDriver protocol directly (no Selenium client dependency). It compares rendered DOM text, and outputs JSON with per-browser status and version to logs and job summary. A failed or unavailable browser fails the job and is not proof of browser capability. The workflow attempts `safaridriver --enable` without elevation on the ephemeral runner; it may still fail due to permissions. Do not run that enabling step on a personal Mac without intending to change its setting. Safari is Safari, not a WebKit substitute. A separate headless Chrome probe requests only the loopback CDP `/json/version` endpoint. Its status is informational and does not fail the job. Chrome and Firefox attempt a synthetic local HTTP download into separate temporary directories and verify the downloaded bytes. Safari download is unverified. A bounded Safari MCP stdio probe attempts only initialize and tools/list, with no browser tool calls; an error or timeout is unverified. Desktop interaction and remote desktop are not tested. No browser security or TLS settings are disabled; temporary server, drivers and profile data are stopped with the job. This test does not expose a persistent service.

To run locally on macOS, execute `python3 probe.py`; its output may contain a machine-generated temporary path only in exceptional error messages. The source is designed for public synthetic CI and needs no external Python packages. A Windows syntax or fixture check cannot prove macOS/browser execution.

Opera is unverified: the image inventory does not list Opera and this workflow does not download or install it. For an intentional follow-up on an isolated macOS machine or disposable runner, obtain the macOS Universal installer from [Opera's official download page](https://www.opera.com/download), verify the publisher signature and compatibility, and use a compatible driver with a fresh temporary profile before attempting the same fixture. A successful installation or launch alone does not establish rendering or download capability. This fallback has not been executed. Safari MCP setup is documented by [WebKit](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/).
